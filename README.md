# VerifyAI — Plagiarism & AI Content Detector

VerifyAI is a world-class, free, and open-source plagiarism checker and AI content detector that runs entirely in your browser.

## Features

- **🧮 5-Algorithm Analysis:** Combines TF-IDF Cosine Similarity, Bigram & Trigram Jaccard, Rabin-Karp Fingerprinting, and Longest Common Subsequence into a single weighted score.
- **🤖 AI Writing Detection:** Detects ChatGPT, Claude, Gemini, and other AI-written text using perplexity, burstiness, lexical diversity, transition word density, and 9 statistical signals.
- **📚 Bulk Document Check:** Upload up to 20 documents at once. Get a full cross-document similarity matrix heatmap to instantly spot duplicate or near-duplicate pairs.
- **📄 PDF, DOCX, TXT Support:** Upload `.pdf`, `.docx`, `.txt`, `.md`, `.csv` files directly. Powered by PDF.js and Mammoth.js — no server required.
- **📊 Full Export Reports:** Download complete analysis as a formatted PDF report (Turnitin-style), structured CSV spreadsheet, or raw JSON data.
- **🔐 100% Private & Offline-Ready:** All processing happens in your browser using Web APIs. Your documents never leave your device. No account, no API key, no tracking.
